# 粉丝社群平台 - 项目架构说明

## 核心架构

**项目由一个个明星所对应的粉丝圈构成，一个用户可以成为多个明星的粉丝。**

```
粉丝社群平台
│
├── 粉丝圈 A（明星：张三）
│   ├── 粉丝（路人粉 / 真爱粉 / 死忠粉）
│   ├── 风纪委员会（member / chairman）
│   ├── 帖子板块
│   ├── 群聊
│   └── 每日签到
│
├── 粉丝圈 B（明星：李四）
│   ├── 粉丝
│   ├── 风纪委员会
│   ├── 帖子板块
│   ├── 群聊
│   └── 每日签到
│
├── 粉丝圈 C（明星：王五）
│   └── ...
│
└── ... 更多粉丝圈
```

---

## 实体关系

```
User (用户)
 │
 ├── 加入 ──→ StarFan ──→ Star (明星) ←── 1:1 ──→ FanCircle (粉丝圈)
 │              │              │
 │              │              ├── StarPost (帖子板块)
 │              │              ├── DisciplineCommittee (风纪委员会)
 │              │              └── FanCheckIn (签到)
 │              │
 │              └── 可加入多个明星的粉丝圈
 │
 ├── StarFollow (关注，无需审核)
 ├── Post (帖子)
 ├── Report (举报)
 └── GroupChat (群聊)
```

---

## 关键规则

### 1. 粉丝圈与明星的关系

| 规则 | 说明 |
|------|------|
| 一个明星 | 对应一个粉丝圈（1:1） |
| 一个用户 | 可加入多个粉丝圈（N:M） |
| 粉丝圈 | 包含粉丝、风纪委、帖子、签到 |

### 2. 用户加入粉丝圈的流程

```
用户 → 关注明星（即时） → 申请成为粉丝（需审核） → 审核通过 → 加入粉丝圈
                                                              │
                                              可选：申请风纪委员会（需审核）
                                              可选：每日签到
                                              可选：发帖（仅粉丝可发）
```

### 3. 粉丝类型

| 类型 | 说明 |
|------|------|
| 路人粉 (casual) | 默认类型 |
| 真爱粉 (true_fan) | 活跃粉丝 |
| 死忠粉 (diehard) | 核心粉丝 |

### 4. 权限体系

| 角色 | 发帖 | 签到 | 审核帖子 | 管理粉丝圈 |
|------|------|------|----------|------------|
| 游客 | ❌ | ❌ | ❌ | ❌ |
| 普通用户 | ❌ | ❌ | ❌ | ❌ |
| 粉丝 | ✅ | ✅ | ❌ | ❌ |
| 风纪委员 | ✅ | ✅ | ✅ | ❌ |
| 管理员 | ✅ | ✅ | ✅ | ✅ |

## 数据库核心表

| 表名 | 说明 | 关键关系 |
|------|------|----------|
| stars | 明星 | 1个明星 → 1个粉丝圈 |
| fan_circles | 粉丝圈 | star_id 唯一 |
| star_fans | 粉丝 | user_id + star_id |
| discipline_committees | 风纪委员会 | user_id + star_id |
| star_posts | 明星帖子关联 | star_id + post_id |
| fan_checkins | 签到 | user_id + star_id + date |
| posts | 帖子 | author_id |
| users | 用户 | - |

## API 路由结构

```
/fan-circles/              ← 粉丝圈（核心入口）
├── /                       粉丝圈列表
├── /{id}                   粉丝圈详情
├── /by-star/{star_id}      通过明星获取粉丝圈
├── /{id}/members           粉丝圈成员
├── /{id}/overview          粉丝圈概览
└── /users/me/joined        我加入的粉丝圈

/stars/                     ← 明星
├── /                       明星列表
├── /{id}/fans/apply        申请粉丝
├── /{id}/fans/{fan_id}/review  审核粉丝
├── /{id}/committee/apply   申请风纪委员
├── /{id}/committee/posts/{pid}/audit  审核帖子
├── /{id}/checkin           签到
└── /{id}/posts             明星帖子板块

/posts/                     ← 帖子
├── /                       帖子列表
├── /recommended            热门推荐
├── /featured               加精帖子
├── /{id}/pin               置顶
└── /{id}/feature           加精

/reports/                   ← 举报
/groups/                    ← 群聊
/auth/                      ← 认证
/users/                     ← 用户
/admin/                     ← 管理员
```
