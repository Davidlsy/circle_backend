# 更新日志 v1.0.51

## 版本信息
- **版本号**: v1.0.51
- **发布日期**: 2026-05-14
- **更新类型**: 功能变更（破坏性变更）

## 更新概述

本次更新限制发帖权限：**仅已通过的粉丝可以发帖**，其他用户只能查看、点赞、收藏、举报。

---

## 变更内容

### 1. 发帖权限控制

| 用户类型 | 发帖 | 查看 | 点赞 | 收藏 | 举报 | 评论 |
|----------|------|------|------|------|------|------|
| 已通过粉丝 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 未通过/未申请粉丝 | ❌ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 普通用户 | ❌ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 管理员 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

### 2. 创建帖子 API 变更

**新增验证逻辑**：创建帖子时检查用户是否是该明星的已通过粉丝。

**错误响应**（非粉丝时）：
```json
{
  "detail": "仅该明星的已通过粉丝可以发帖，请先申请成为粉丝"
}
```

**完整发帖流程**：
```
1. 关注明星（StarFollow，无需审核）
2. 申请成为粉丝（StarFan，需审核）
3. 粉丝审核通过（status=approved）
4. 发帖 ✅
```

### 3. 权限验证逻辑

```python
# 管理员：跳过粉丝验证，直接发帖
if current_user.is_superuser:
    pass  # 允许发帖

# 普通用户：检查是否是已通过的粉丝
else:
    is_fan = StarFan(star_id=star_id, user_id=user_id, status="approved")
    if not is_fan:
        raise 403 "仅该明星的已通过粉丝可以发帖"
```

## API 变更详情

### POST /posts/ - 创建帖子

**新增验证**：
- 验证用户是否是 `star_id` 对应明星的已通过粉丝
- 管理员（is_superuser）跳过验证

**请求体不变**：
```json
{
  "title": "帖子标题",
  "content": "帖子内容",
  "content_format": "markdown",
  "is_published": true,
  "star_id": 1
}
```

**可能的错误响应**：

| 状态码 | 说明 |
|--------|------|
| 403 | 仅该明星的已通过粉丝可以发帖 |
| 404 | 明星不存在或已禁用 |
