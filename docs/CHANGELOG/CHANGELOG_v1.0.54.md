# 更新日志 v1.0.54

## 版本信息
- **版本号**: v1.0.54
- **发布日期**: 2026-05-15
- **更新类型**: Bug 修复

## 更新概述

修复明星板块发帖接口（`POST /stars/{id}/posts`）缺少粉丝身份验证的问题。现在**所有发帖入口**均强制验证用户是否为该明星的已通过粉丝。

---

## 问题描述

V1.0.51 在通用发帖接口 `POST /posts/` 中添加了粉丝身份验证，但遗漏了明星板块发帖接口 `POST /stars/{id}/posts`，导致非粉丝用户仍可通过该接口发帖。

---

## 修复内容

### 修复前

| 发帖入口 | 粉丝验证 | 状态 |
|----------|----------|------|
| `POST /posts/` | ✅ 有验证 | 正常 |
| `POST /stars/{id}/posts` | ❌ 无验证 | **存在漏洞** |

### 修复后

| 发帖入口 | 粉丝验证 | 状态 |
|----------|----------|------|
| `POST /posts/` | ✅ 有验证 | 正常 |
| `POST /stars/{id}/posts` | ✅ 有验证 | **已修复** |

### 验证逻辑

```python
# 管理员：跳过粉丝验证
if not current_user.is_superuser:
    is_fan = StarFan(star_id=star_id, user_id=user_id, status="approved")
    if not is_fan:
        raise 403 "仅该明星的已通过粉丝可以发帖，请先申请成为粉丝"
```

---

## 错误响应

非粉丝用户调用发帖接口时：

```json
{
  "detail": "仅该明星的已通过粉丝可以发帖，请先申请成为粉丝"
}
```

**HTTP 状态码**: 403 Forbidden
