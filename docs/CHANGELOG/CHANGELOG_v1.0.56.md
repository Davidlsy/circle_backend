## 更新概述

本次更新新增**基于热度的帖子推荐功能**。系统根据浏览量、点赞数、评论数、收藏数等维度计算帖子热度，并加入时间衰减因子，向用户推荐最热门的帖子。

---

## 热度算法

### 计算公式

```
热度分数 = (浏览量×1 + 点赞数×5 + 评论数×10 + 收藏数×8) / 发布小时数^1.5
```

### 权重说明

| 维度 | 权重 | 说明 |
|------|------|------|
| 浏览量 | ×1 | 基础互动 |
| 点赞数 | ×5 | 中度互动 |
| 收藏数 | ×8 | 较高认可 |
| 评论数 | ×10 | 深度互动，权重最高 |

### 时间衰减

- 分母为 `发布小时数^1.5`
- 越新的帖子，衰减越小，热度越高
- 越旧的帖子，衰减越大，热度自然降低
- 保证推荐结果既有热门老帖，也有新晋热帖

## 新增接口

| 接口 | 方法 | 路径 | 功能说明 | 权限 |
|------|------|------|----------|------|
| 推荐帖子 | GET | `/posts/recommended` | 获取热门推荐帖子 | 公开 |

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | int | 否 | 页码（默认 1） |
| page_size | int | 否 | 每页数量（默认 20，最大 50） |
| star_id | int | 否 | 按明星筛选推荐 |

### 返回示例

```json
{
  "posts": [
    {
      "id": 123,
      "title": "热门帖子标题",
      "content_summary": "帖子摘要...",
      "author_id": 1,
      "author_name": "user1",
      "view_count": 1500,
      "like_count": 200,
      "comment_count": 50,
      "collect_count": 80,
      "heat_score": 85.3241,
      "is_pinned": false,
      "is_featured": true,
      "created_at": "2026-05-14T10:00:00"
    }
  ],
  "total": 500,
  "page": 1,
  "page_size": 20
}
```

## 使用示例

### 获取全局推荐
```bash
curl "http://localhost:8000/posts/recommended?page=1&page_size=10"
```

### 获取某明星板块的推荐
```bash
curl "http://localhost:8000/posts/recommended?star_id=1&page=1&page_size=10"
```
