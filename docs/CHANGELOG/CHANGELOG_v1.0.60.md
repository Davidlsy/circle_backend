# 更新日志 v1.0.60

## 版本信息
- **版本号**: v1.0.60
- **发布日期**: 2026-05-15
- **更新类型**: 功能新增

## 更新概述

本次更新新增**用户个人主页帖子展示功能**。粉丝可以在个人主页展示发过的帖子，支持限制展示数量和时间范围。

---

## 新增功能

### 1. 用户资料

| 接口 | 方法 | 路径 | 功能说明 | 权限 |
|------|------|------|----------|------|
| 用户公开资料 | GET | `/users/{user_id}` | 获取用户资料（含粉丝牌） | 公开 |
| 我的完整资料 | GET | `/users/me/profile` | 获取我的完整个人资料 | 登录 |

#### 1.1 返回示例

```json
{
  "id": 1,
  "username": "user1",
  "avatar": "https://...",
  "bio": "个人简介",
  "display_badge": {
    "badge_name": "张三的死忠粉",
    "badge_color": "#FFD700",
    "star": {"name": "张三", ...}
  },
  "stats": {
    "post_count": 50,
    "like_received": 1000,
    "comment_received": 200
  }
}
```

### 2. 用户帖子展示

| 接口 | 方法 | 路径 | 功能说明 | 权限 |
|------|------|------|----------|------|
| 用户帖子（限制版） | GET | `/users/{user_id}/posts` | 获取用户帖子（数量+时间限制） | 公开 |
| 用户帖子（全部） | GET | `/users/{user_id}/posts/all` | 获取用户所有帖子 | 公开 |
| 用户在某明星的帖子 | GET | `/users/{user_id}/posts/by-star/{star_id}` | 获取用户在某明星板块的帖子 | 公开 |

#### 2.1 帖子展示限制

| 参数 | 默认值 | 最大值 | 说明 |
|------|--------|--------|------|
| `limit` | 10 | 50 | 展示数量限制 |
| `days` | 30 | 365 | 时间范围（天） |

#### 2.2 使用示例

```bash
# 获取用户最近30天内的帖子（默认）
curl "http://localhost:8000/users/1/posts"

# 获取用户最近7天内的帖子，最多展示20条
curl "http://localhost:8000/users/1/posts?limit=20&days=7"

# 获取用户最近90天内的帖子
curl "http://localhost:8000/users/1/posts?days=90"

# 获取用户所有帖子（无限制）
curl "http://localhost:8000/users/1/posts/all"

# 获取用户在某明星板块的帖子
curl "http://localhost:8000/users/1/posts/by-star/1?days=30"
```

#### 2.3 返回示例

```json
{
  "posts": [
    {
      "id": 1,
      "title": "帖子标题",
      "content_summary": "内容摘要...",
      "like_count": 100,
      "comment_count": 20,
      "is_pinned": false,
      "is_featured": true,
      "star_id": 1,
      "star_name": "张三",
      "created_at": "2026-05-15T10:00:00"
    }
  ],
  "total": 50,
  "page": 1,
  "page_size": 20,
  "limit": 10,
  "days": 30,
  "time_threshold": "2026-04-15T10:00:00"
}
```

## 功能特点

### 数量限制

- 默认展示最近 10 条帖子
- 最大可设置 50 条
- 适用于个人主页的有限展示区域

### 时间限制

- 默认展示最近 30 天内的帖子
- 最大可设置 365 天
- 可按需调整时间范围

### 排序规则

- 置顶帖优先显示
- 按创建时间倒序排列

### 筛选功能

- 可按明星板块筛选帖子
- 仅返回已审核通过的帖子

## 使用场景

### 个人主页展示

```
用户个人主页
├── 用户头像、昵称、简介
├── 粉丝牌（展示一个）
├── 统计数据（帖子数、获赞数、评论数）
└── 最近帖子（限制数量和时间）
    └── 最近30天内的10条帖子
```

### 粉丝圈成员页

```
粉丝圈成员详情
├── 用户基本信息
├── 粉丝类型（路人粉/真爱粉/死忠粉）
└── 在该粉丝圈的帖子
    └── /users/{id}/posts/by-star/{star_id}
```
