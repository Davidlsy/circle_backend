## 1. 用户模块

### 1.1 功能概述
用户管理、认证、个人资料维护。

### 1.2 API接口列表

| 接口 | 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|------|
| 用户注册 | POST | `/auth/register` | 创建新账号 | 公开 |
| 用户登录 | POST | `/auth/login` | 获取JWT令牌 | 公开 |
| 获取当前用户 | GET | `/users/me` | 查看我的信息 | 登录 |
| 更新个人资料 | PUT | `/users/me` | 修改昵称/头像等 | 登录 |
| 修改密码 | PUT | `/users/me/password` | 修改登录密码 | 登录 |
| 用户详情 | GET | `/users/{id}` | 查看其他用户信息 | 登录 |
| 用户列表 | GET | `/users/` | 查看所有用户 | 管理员 |

### 1.3 用户角色

| 角色 | 说明 |
|------|------|
| 普通用户 | 基础功能 |
| 管理员 | 全部管理权限 |

## 2. 帖子模块

### 2.1 功能概述
帖子发布、浏览、互动（点赞、收藏、评论）。

### 2.2 发帖权限
- **已通过的粉丝** 或 **管理员** 可以发帖
- 普通用户只能查看、点赞、收藏、举报

### 2.3 API接口列表

| 接口 | 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|------|
| 创建帖子 | POST | `/posts/` | 发布新帖子 | 粉丝/管理员 |
| 帖子列表 | GET | `/posts/` | 浏览帖子列表 | 公开 |
| 帖子详情 | GET | `/posts/{id}` | 查看帖子详情 | 公开 |
| 更新帖子 | PUT | `/posts/{id}` | 修改自己的帖子 | 作者 |
| 删除帖子 | DELETE | `/posts/{id}` | 删除帖子 | 作者/管理员 |
| 点赞帖子 | POST | `/posts/{id}/like` | 点赞/取消点赞 | 登录 |
| 收藏帖子 | POST | `/posts/{id}/collect` | 收藏/取消收藏 | 登录 |
| 评论帖子 | POST | `/posts/{id}/comments` | 发表评论 | 登录 |
| 评论列表 | GET | `/posts/{id}/comments` | 查看评论 | 公开 |
| 我的帖子 | GET | `/posts/my` | 查看我发布的帖子 | 登录 |
| 我的收藏 | GET | `/posts/my/collections` | 查看我收藏的帖子 | 登录 |

### 2.4 帖子状态

| 状态 | 说明 |
|------|------|
| pending | 待审核 |
| approved | 已通过 |
| rejected | 已驳回 |

## 4. 风纪委员会模块

### 4.1 功能概述
粉丝模块内部的审核组织，成员负责审核该明星板块下的帖子。

### 4.2 加入条件
1. 必须是该明星的**已通过粉丝**
2. 申请加入风纪委员会
3. 经过管理员/委员长审核

### 4.3 角色权限

| 角色 | 权限 |
|------|------|
| member（成员） | 审核帖子 |
| chairman（委员长） | 审核帖子 + 审核风纪委员申请 |

### 4.4 API接口列表

| 接口 | 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|------|
| 申请加入 | POST | `/stars/{id}/committee/apply` | 申请成为风纪委员 | 已通过的粉丝 |
| 待审核列表 | GET | `/stars/{id}/committee/pending` | 查看待审核申请 | 管理员/委员长 |
| 审核申请 | POST | `/stars/{id}/committee/{app_id}/review` | 通过/拒绝申请 | 管理员/委员长 |
| 成员列表 | GET | `/stars/{id}/committee` | 查看已通过成员 | 公开 |
| 我的申请 | GET | `/stars/users/me/committee-applications` | 我的申请记录 | 登录 |
| 辞去职务 | DELETE | `/stars/{id}/committee/me` | 辞去风纪委员 | 成员 |
| 待审核帖子 | GET | `/stars/{id}/committee/posts/pending` | 查看待审核帖子 | 风纪委员 |
| 审核帖子 | POST | `/stars/{id}/committee/posts/{post_id}/audit` | 通过/驳回帖子 | 风纪委员 |

## 5. 签到模块

### 5.1 功能概述
粉丝每日签到打卡，支持连续签到奖励。

### 5.2 签到时间规则
- **04:00 - 23:59:59**: 归属当天
- **00:00 - 03:59:59**: 归属前一天

### 5.3 连续签到奖励

| 连续天数 | 积分 |
|----------|------|
| 1-2 天 | 1 分 |
| 3-6 天 | 2 分 |
| 7-29 天 | 3 分 |
| 30+ 天 | 5 分 |

### 5.4 API接口列表

| 接口 | 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|------|
| 签到打卡 | POST | `/stars/{id}/checkin` | 每日签到 | 已通过的粉丝 |
| 签到状态 | GET | `/stars/{id}/checkin/status` | 我的签到统计 | 已通过的粉丝 |
| 签到日历 | GET | `/stars/{id}/checkin/calendar` | 某月已签到日期 | 已通过的粉丝 |
| 排行榜 | GET | `/stars/{id}/checkin/rank` | 签到排行榜 | 公开 |
| 签到历史 | GET | `/stars/{id}/checkin/history` | 我的签到记录 | 已通过的粉丝 |

## 7. 举报模块

### 7.1 功能概述
用户举报违规帖子，管理员审核处理。

### 7.2 举报原因分类

| 原因 | 说明 |
|------|------|
| 垃圾广告 | 推广广告、营销内容 |
| 色情低俗 | 涉黄内容 |
| 虚假信息 | 谣言、不实信息 |
| 人身攻击 | 辱骂、恐吓、骚扰 |
| 侵犯版权 | 盗用他人作品 |
| 违法违规 | 违反法律法规 |
| 恶意刷屏 | 重复无意义内容 |
| 其他 | 其他违规情况 |

### 7.3 API接口列表

| 接口 | 方法 | 路径 | 功能 | 权限 |
|------|------|------|------|------|
| 举报原因列表 | GET | `/reports/reasons` | 获取举报分类 | 公开 |
| 提交举报 | POST | `/reports/` | 举报帖子 | 登录 |
| 我的举报 | GET | `/reports/my` | 查看我的举报 | 登录 |
| 举报列表 | GET | `/reports/` | 查看所有举报 | 管理员 |
| 举报统计 | GET | `/reports/stats` | 举报统计数据 | 管理员 |
| 举报详情 | GET | `/reports/{id}` | 查看举报详情 | 管理员/举报人 |
| 处理举报 | POST | `/reports/{id}/handle` | 处理举报 | 管理员 |

### 7.4 举报状态

| 状态 | 说明 |
|------|------|
| pending | 待处理 |
| processing | 处理中 |
| resolved | 举报成立（帖子自动驳回） |
| dismissed | 举报不成立 |

## 9. 功能权限总览

### 9.1 用户类型权限矩阵

| 功能 | 普通用户 | 已通过粉丝 | 风纪委员 | 管理员 |

| 举报帖子 | ✅ | ✅ | ✅ | ✅ |
| 发表评论 | ✅ | ✅ | ✅ | ✅ |
